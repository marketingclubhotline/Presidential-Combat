# Recorded audience laughter

Place a licensed, edited 1–2 second MP3 at `sitcom-laugh-short.mp3`.
The game automatically decodes it over the existing synthesized `crowdLaugh` fallback.
Use a brief audience chuckle with short fade-in/out, normalize conservatively, and keep fighter voices intelligible.
